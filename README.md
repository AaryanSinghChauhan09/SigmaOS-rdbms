# SigmaOS-rdbms

SigmaOS component: **rdbms**.

## Overview

Part of the SigmaOS modular component ecosystem. Built with Rust, following SOLID
principles, modularity, fail-fast error handling, and secure defaults.

## Structure

- `src/lib.rs` — library implementation
- `src/main.rs` — CLI entry point
- `docs/` — architecture, principles, API, testing, security docs

## Principles

SOLID, DRY, KISS, YAGNI, fail-fast, defensive programming, information hiding,
encapsulation, abstraction, layered design, race-free concurrency, deterministic
testing, reproducible builds, secure defaults, least privilege.
